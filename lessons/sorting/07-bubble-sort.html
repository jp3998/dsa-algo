Derivation of Bubble Sort: Repair of Adjacent Inversions

"Bubble Sort is frequently presented as an arbitrary, inefficient toy. But when viewed through the lens of discrete mathematics, it emerges naturally from a profound principle: an array is sorted if and only if it contains zero adjacent inversions. Every swap is a surgical repair that destroys exactly one unit of disorder."

7.1 Measuring Disorder: The Concept of an Inversion

In Chapter 1, we specified that an array is sorted if and only if $A[i] \le A[i+1]$ for every index $i$.

If an array is not sorted, how can we mathematically measure how far it is from being sorted?

The answer is the concept of an inversion.

Definition 7.1 (Inversion)

Given an array $A[0 \dots n-1]$, an inversion is an ordered pair of indices $(i, j)$ such that: $$i < j \quad \text{and} \quad A[i] > A[j] \tag{7.1}$$

The set of all inversions in $A$ is denoted $\text{Inv}(A)$: $$\text{Inv}(A) = \{(i, j) \mid 0 \le i < j < n \text{ and } A[i] > A[j]\} \tag{7.2}$$

For example, in the array $A = [4, 1, 3, 2]$:

  • Pair $(0, 1)$: $A[0] = 4 > A[1] = 1$ (Inversion!)
  • Pair $(0, 2)$: $A[0] = 4 > A[2] = 3$ (Inversion!)
  • Pair $(0, 3)$: $A[0] = 4 > A[3] = 2$ (Inversion!)
  • Pair $(1, 2)$: $A[1] = 1 < A[2] = 3$ (Not an inversion)
  • Pair $(1, 3)$: $A[1] = 1 < A[3] = 2$ (Not an inversion)
  • Pair $(2, 3)$: $A[2] = 3 > A[3] = 2$ (Inversion!)

Thus, $\text{Inv}(A) = \{(0, 1), (0, 2), (0, 3), (2, 3)\}$, and $|\text{Inv}(A)| = 4$.

Lemma 7.1 (Zero Inversions Characterizes Sorted Order)

An array $A$ is in non-decreasing sorted order if and only if $|\text{Inv}(A)| = 0$.

Furthermore, we have the following critical structural lemma:

Lemma 7.2 (Existence of Adjacent Inversion)

If an array $A$ is not sorted ($|\text{Inv}(A)| > 0$), there must exist at least one pair of adjacent indices $j$ and $j+1$ such that: $$A[j] > A[j+1] \tag{7.3}$$

Proof: Suppose for contradiction that no such adjacent pair exists. Then for all $j \in \{0, \dots, n-2\}$, we have $A[j] \le A[j+1]$. By transitivity (from Chapter 1), $A[i] \le A[j]$ for all $i < j$, which means $|\text{Inv}(A)| = 0$, contradicting the assumption that $A$ was not sorted. ■

7.2 The Mathematics of the Adjacent Transposition

Lemma 7.2 suggests an immediate computational strategy: whenever you find an adjacent inversion, swap the two elements!

Swapping two adjacent elements is called an adjacent transposition. What happens to the inversion set when we perform this swap?

Theorem 7.1 (Inversion Annihilation Theorem)

Let $A[j] > A[j+1]$. If we swap elements $A[j]$ and $A[j+1]$, the total number of inversions in the array decreases by strictly $1$: $$|\text{Inv}(A_{\text{after}})| = |\text{Inv}(A_{\text{before}})| - 1 \tag{7.4}$$

Proof of Theorem 7.1:

Consider any other pair of indices $(p, q)$ in the array:

  • If neither $p$ nor $q$ equals $j$ or $j+1$, their positions and values are untouched. Their inversion status does not change.
  • If one index is $p < j$ (an element to the left): before the swap, $p$ preceded both $j$ and $j+1$; after the swap, $p$ still precedes both. Thus the set of pairs $\{(p, j), (p, j+1)\}$ contains the exact same elements in the exact same order.
  • Similarly, if one index is $q > j+1$ (an element to the right): $q$ succeeds both before and after the swap.

The only pair whose relative position changes is the pair $(j, j+1)$. Since $A[j] > A[j+1]$ before the swap, $(j, j+1)$ was an inversion. After the swap, the smaller element is at index $j$ and the larger is at $j+1$, so $(j, j+1)$ is no longer an inversion. All other pairs remain identical. Thus, exactly one inversion is destroyed: $|\text{Inv}(A_{\text{after}})| = |\text{Inv}(A_{\text{before}})| - 1$. ■

7.3 Derivation of the Bubble Sort Algorithm

We now know that swapping adjacent inversions makes steady progress toward sorted order. But in what systematic order should we inspect and swap adjacent pairs?

Suppose we make a complete left-to-right pass across the array, comparing $A[j]$ and $A[j+1]$ for $j = 0, 1, 2, \dots, n-2$, and swapping whenever $A[j] > A[j+1]$.

What happens to the maximum element in the array during this pass?

The Maximum Propagation Lemma

During a left-to-right sweep across an array of length $n$, the maximum element of the array is carried along with the comparison window and is guaranteed to end up at the final index $A[n-1]$.

The Complete Algorithmic Specification

Because pass $1$ places the largest element at $A[n-1]$, pass $2$ needs only to sweep up to $A[n-2]$ to place the second largest element at $A[n-2]$. In general, pass $i$ sweeps up to $A[n-i-1]$. 

function bubble_sort(A, n):
    for i from 0 to n - 2:
        for j from 0 to n - i - 2:
            if A[j] > A[j + 1]:
                swap(A[j], A[j + 1])

Formal Verification of the Outer Loop Invariant

Formal Loop Invariant for Bubble Sort

At the start of iteration $i$ of the outer loop:

  1. The subarray $A[n-i \dots n-1]$ is in sorted order: $$A[n-i] \le A[n-i+1] \le \dots \le A[n-1]$$
  2. Every element in the prefix $A[0 \dots n-i-1]$ is less than or equal to every element in the suffix: $$\forall p < n-i \text{ and } \forall q \ge n-i, \quad A[p] \le A[q]$$

Let us verify the three obligations:

  • Initialization ($i = 0$): Suffix $A[n \dots n-1]$ is empty. An empty subarray is vacuously sorted, and all conditions hold trivially.
  • Maintenance: During pass $i$, the inner loop bubbles the maximum element of $A[0 \dots n-i-1]$ to position $A[n-i-1]$. By the induction hypothesis, this element is $\le$ all elements in $A[n-i \dots n-1]$. Thus, the sorted suffix expands to $A[n-i-1 \dots n-1]$. Invariant holds for $i + 1$.
  • Termination ($i = n - 1$): The sorted suffix is $A[1 \dots n-1]$, and $A[0] \le A[1]$. Therefore, the entire array $A[0 \dots n-1]$ is sorted! Postcondition $Q$ is achieved. ■

7.4 Complexity Analysis: The Quadratic Cost

How many comparisons does standard Bubble Sort execute?

In pass $i = 0$, the inner loop executes $n - 1$ comparisons.
In pass $i = 1$, it executes $n - 2$ comparisons.
In general, pass $i$ executes $n - i - 1$ comparisons, until the final pass executes $1$ comparison:

$$C(n) = \sum_{i=0}^{n-2} (n - i - 1) = (n - 1) + (n - 2) + \dots + 2 + 1 \tag{7.5}$$

This is the celebrated arithmetic progression Gauss summed as a schoolboy:

$$C(n) = \frac{(n - 1)n}{2} = \frac{1}{2}n^2 - \frac{1}{2}n = \Theta(n^2) \tag{7.6}$$

Notice that standard Bubble Sort makes exactly $\frac{n(n-1)}{2}$ comparisons on every single input—even if the array was already sorted before it started!

7.5 The Adaptive Optimization: Early-Exit Flag

Can we make Bubble Sort smarter?

Recall Lemma 7.2: an array is sorted if and only if it contains zero adjacent inversions.

If the inner loop sweeps through the entire unsorted prefix without executing a single swap, then no adjacent inversions exist in the array!

Therefore, we can track whether a swap occurred using a boolean flag swapped. If swapped == false at the end of a pass, we halt immediately! 

function adaptive_bubble_sort(A, n):
    for i from 0 to n - 2:
        swapped = false
        for j from 0 to n - i - 2:
            if A[j] > A[j + 1]:
                swap(A[j], A[j + 1])
                swapped = true
        if not swapped:
            break  // Array is already sorted! Halt immediately.
Complexity Impact of Early Exit
  • Best Case (Already Sorted Array): In pass 0, the algorithm performs $n - 1$ comparisons, detects $0$ swaps, and terminates immediately! Running time drops from $\Theta(n^2)$ to $\Theta(n)$!
  • Worst Case (Reverse Sorted Array): Performs all $\frac{n(n-1)}{2}$ comparisons and $\frac{n(n-1)}{2}$ swaps: $\Theta(n^2)$.

7.6 Formal Proof of Stability

In Chapter 1, we introduced stability: elements with equal keys must maintain their original relative order. Is Bubble Sort stable?

Theorem 7.2 (Stability of Bubble Sort)

Bubble sort using the comparison predicate $A[j] > A[j+1]$ is stable.

Proof:

Consider two identical elements $A[p]$ and $A[q]$ with $p < q$ and $\text{key}(A[p]) = \text{key}(A[q])$.

For their relative order to reverse, $A[p]$ would have to be swapped with $A[q]$ during some pass. However, the swap condition is strictly: $$A[j] > A[j+1]$$ When $A[j]$ and $A[j+1]$ have equal keys, $A[j] > A[j+1]$ evaluates to False. No swap occurs. The algorithm never swaps equal keys, and elements can only move across each other via adjacent swaps. Therefore, $A[p]$ always remains to the left of $A[q]$. Bubble sort is unconditionally stable. ■

7.7 Analytical Exercises

Problem 7.1 — The Maximum Inversion Theorem
Prove that for any array of $n$ distinct elements, the maximum possible number of inversions is: $$\frac{n(n-1)}{2}$$ Characterize the exact input permutation that achieves this maximum.

Proof:

An inversion is an ordered pair of indices $(i, j)$ with $0 \le i < j < n$. The total number of pairs of indices $(i, j)$ in an array of size $n$ is given by the binomial coefficient: $$\binom{n}{2} = \frac{n(n-1)}{2}$$

Since every inversion must be one of these pairs, $|\text{Inv}(A)| \le \frac{n(n-1)}{2}$.

To achieve this maximum, every single pair $(i, j)$ must be an inversion. That is, for all $i < j$, we must have $A[i] > A[j]$. This occurs if and only if the array is in strictly descending order (reverse sorted): $$A[0] > A[1] > A[2] > \dots > A[n-1]$$ Therefore, a reverse-sorted array of size $n$ has exactly $\frac{n(n-1)}{2}$ inversions, representing the maximum disorder possible in $S_n$. ■

Problem 7.2 — Accidental Loss of Stability: Replacing $>$ with $\ge$
Suppose a programmer accidentally writes the swap condition as: if A[j] >= A[j + 1]: swap(A[j], A[j + 1]). Does the algorithm still correctly sort the array? Does it remain stable? Provide a concrete counterexample with proof.

Analysis:

Correctness: The algorithm will still terminate and sort the array, because elements will still bubble to their appropriate positions.

Stability: Stability is completely destroyed!

Concrete Counterexample:
Consider the input array $A = [3_a, 3_b, 1]$, where $3_a$ and $3_b$ have equal key value $3$.

  • Step 1: Compare $A[0] = 3_a$ and $A[1] = 3_b$. Since $3_a \ge 3_b$ is True, they are swapped! Array becomes: $[3_b, 3_a, 1]$.
  • Step 2: Compare $A[1] = 3_a$ and $A[2] = 1$. Since $3_a \ge 1$, they swap. Array becomes: $[3_b, 1, 3_a]$.
  • Pass 2: $3_b$ and $1$ swap. Final array: $[1, 3_b, 3_a]$.

In the output, $3_b$ appears before $3_a$, reversing their original relative order. The algorithm is now unstable. This demonstrates why the strict inequality $>$ is a critical design requirement for stability in comparison sorting. ■

Summary & Transition to Selection Sort

In this chapter, we derived Bubble Sort from first principles:

  • Disorder is quantified by the inversion count $|\text{Inv}(A)|$.
  • An array is sorted if and only if it has zero adjacent inversions.
  • Every adjacent transposition destroys strictly $1$ inversion.
  • A left-to-right sweep bubbles the maximum element into the suffix, giving a quadratic complexity of $\Theta(n^2)$.
  • Tracking swaps with an early-exit flag provides an adaptive best case of $\Theta(n)$.

While Bubble Sort is conceptually clean, it performs many unnecessary swaps (up to $\Theta(n^2)$ writes to memory). Can we design an algorithm that sorts while making at most $\mathcal{O}(n)$ swaps?

In Chapter 8, we derive Selection Sort by changing our invariant: instead of repairing adjacent inversions, we systematically locate the global minimum and place it in a single swap pass.
